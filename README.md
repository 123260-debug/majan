# 麻雀オンライン

ブラウザだけで遊べる、部屋コード方式のオンライン麻雀です。サーバーは不要で、GitHub Pages でそのまま公開できます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | ページの骨組み |
| `style.css` | 見た目(卓・牌・ロビー) |
| `game.js` | ゲームのルール・通信・描画 |
| `README.md` | このファイル(リポジトリのトップに表示されます) |

## 遊び方

1. 1人が「部屋を作る」を押すと、4桁の部屋コードが出ます。
2. ほかの人は同じページを開き、コードを入れて「入室」します。
3. ホストが「対局開始」を押すと始まります。空席はCPUが入ります。

## GitHub での公開手順(初めての方向け)

### 1. アカウントとリポジトリを作る
1. https://github.com でアカウントを作ります(無料)。
2. 右上の「＋」→「New repository」を押します。
3. Repository name に `mahjong-online` と入力し、「Public」を選んで「Create repository」を押します。

### 2. ファイルをアップロードする
1. 作成したリポジトリのページで「uploading an existing file」(または「Add file」→「Upload files」)を押します。
2. `index.html` `style.css` `game.js` `README.md` の4つをドラッグ&ドロップします。
3. 下の「Commit changes」を押します。これで保存(コミット)されます。

### 3. 公開する(GitHub Pages)
1. リポジトリの「Settings」→ 左の「Pages」を開きます。
2. 「Branch」を `main`、フォルダを `/ (root)` にして「Save」を押します。
3. 1〜2分待つと、次のURLで遊べます。

   `https://あなたのユーザー名.github.io/mahjong-online/`

このURLを友達に送れば一緒に遊べます。

### 4. コードを更新(上書き)する
**ブラウザだけの場合**
1. リポジトリのページで「Add file」→「Upload files」を押します。
2. 新しいファイルをドラッグします。**同じファイル名なら自動で上書き**されます。
3. 「Commit changes」を押します。
4. 公開ページは `Ctrl + Shift + R`(Macは `Cmd + Shift + R`)で強制再読み込みします。

**1つのファイルだけ直したい場合**
1. リポジトリでファイル名をクリックし、右上の鉛筆アイコン(Edit)を押します。
2. 内容を直して「Commit changes」を押します。

**Git を使う場合**
```
git clone https://github.com/あなたのユーザー名/mahjong-online.git
cd mahjong-online
（ファイルを上書きコピー）
git add .
git commit -m "更新内容のメモ"
git push
```

## 自分のパソコンで試す
`index.html` をダブルクリックでも動きますが、通信の確認はローカルサーバーが確実です。

```
python3 -m http.server 8000
```
ブラウザで `http://localhost:8000` を2つのタブで開き、片方で部屋を作り、もう片方でコードを入れて入室します。

## 入室できないとき
- 部屋コードが4桁の数字で合っているか確認してください。
- ホストが部屋を作った後、ページを閉じたり再読み込みしていないか確認してください(閉じると部屋が消えます)。
- 通信は PeerJS の無料の公開サーバーを使っています。混雑すると失敗することがあるので、少し待って再試行してください。
- 別々の回線(自宅とスマホ回線など)だと、お使いのルーターによっては直接つながらない場合があります。その場合は同じWi-Fiで試してください。
- 画面に赤い文字でエラー内容が出ます。内容を教えてもらえれば原因を絞れます。
